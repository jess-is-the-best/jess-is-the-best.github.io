ConfigKit v2.4.1

A lightweight Python library for loading and validating application configuration files with schema support.

Features

  • JSON, YAML, and TOML support
  • Schema validation with helpful error messages
  • Environment variable interpolation
  • Hot-reload with file watching

Quick Start

pip install configkit

from configkit import Config, Environment

config = Config.load(
    path="app.toml",
    env=Environment.detect(),
    strict=True
)

# Access nested values
db_url = config.get("database.url")
pool_size = config.get("database.pool_size", default=5)

Schema Validation

from configkit import Schema, Field

schema = Schema({
    "database": {
        "url": Field(str, required=True),
        "pool_size": Field(int, default=5, min=1, max=100),
    },
    "server": {
        "host": Field(str, default="0.0.0.0"),
        "port": Field(int, default=8080),
    }
})

config = Config.load("app.toml", schema=schema)
