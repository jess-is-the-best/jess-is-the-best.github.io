Config Loader v2 - Quick Start

This module provides configuration loading utilities for Python applications.

Installation

pip install config-loader-v2

import json
from pathlib import Path

def load_config(path="config.json"):
    with open(path) as f:
        return json.load(f)

API Reference

The load_config() function accepts a path parameter and returns a dictionary.
